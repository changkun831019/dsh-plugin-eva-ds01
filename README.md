# DS-01 求索 · DeepSeek Harness 的 EVA 风格皮肤

给 DeepSeek Harness 桌面版换上 EVA 风格的开机动画和工作状态。开机是一次出击；AI 干活的每一步，思考、调用工具、派子代理、等你批准、上下文压缩、出错、完成，都有对应的画面。

机甲、驾驶员、配乐和代码都是用 AI 做的。非官方同人作品，和 DeepSeek、《新世纪福音战士》的版权方都没有关系。

## 装上以后有什么

**开机**：每天第一次打开 DSH 放完整版（约 15 秒，停在「PRESS ENTER」：Enter 有声、Esc 静音），同一天再打开只放约 1 秒的短版。点「新会话」进到空白首页，右侧是驾驶员特写；在首页空白处双击，重放完整开机。

**干活的时候**：

- 深色主题换成黑底橙色，浅色主题换成纸色底。
- 底部状态栏：阶段、这一轮计时、同步率、电源、单元、工具数、本地时间。
  - **同步率**＝提示缓存命中率。命中的那部分输入按缓存价收费，比没命中的便宜得多，所以同步率越高越省钱。
  - **电源**＝剩下的上下文。用完了 DSH 会压缩上下文，画面上就是「外部电源接续」。
  - **单元**：01 是主驾驶员，02 起是出击中的子代理。
  - 「限制器 解除」：完全权限模式下才出现。
- 思考：琥珀色扫描线扫过对话区。
- 调用工具：右上角闪入六角标签（比如「BASH 执行」），完成转绿，失败转红。
- 驾驶员画面窗：右下角，表情跟着状态换。
- 派子代理：左下角「UNIT-02 出击」。
- 等你批准：全窗红色六角警报墙闪约 2.5 秒，然后退成四周红框。批准或拒绝还是点 DSH 自己的卡片。
- 出错：整窗抖一下，加「异常、检出。」字卡。
- 完成：驾驶员画面窗报告用了几次工具、用时多久，不盖屏；跑了 3 分钟以上的长任务才出全屏「任务、完成。」字卡。
- 状态栏上的「动效」可以在 全效 → 简洁 → 关 之间切换；「音效」默认关，都是浏览器现场合成的电子音。

## 安装

**最省事**：把下面这句话发给你的 DeepSeek Harness，让它自己装：

> 帮我安装 DSH 插件 github:changkun831019/dsh-plugin-eva-ds01，装好以后告诉我怎么重启生效

**自己装**：在 DSH 的「插件」页安装，地址填 `github:changkun831019/dsh-plugin-eva-ds01`。或者在终端里运行（macOS）：

```bash
'/Applications/DeepSeek Harness.app/Contents/Resources/runtime/cli/bin/dsh' plugin --profile desktop add github:changkun831019/dsh-plugin-eva-ds01
```

装好以后**退出并重新打开** DeepSeek Harness。

## 卸载或暂时关掉

- 暂时关掉：DSH「插件」页里把 `dsh-plugin-eva-ds01` 的开关关掉。
- 只关动效、保留开机：状态栏「动效」切到「关」。
- 卸载：

```bash
'/Applications/DeepSeek Harness.app/Contents/Resources/runtime/cli/bin/dsh' plugin --profile desktop remove dsh-plugin-eva-ds01
```

## 配乐

默认是插件自带的原创进行曲「出击」。开机画面上点「♪ 换开机配乐（选本机文件）」可以换成你电脑上的音频文件，文件只存在 DSH 自己的本地存储里；「恢复默认配乐」换回「出击」。自选配乐的卡点是按《EM20#070720》开头那一段调的。

## 适配

- DeepSeek Harness Desktop 0.2.1-rc.5、0.2.2-rc.1 上实测可用。DSH 还在 0.2.x 测试版，以后升级如果页面结构变了，部分动效可能失效。
- 标题字用 macOS 自带的宋体-简，在 Mac 上效果最好；其他系统会依次用 Noto Serif SC、思源宋体，没有的话退到系统宋体。
